# Capture Idea

## When to Use
When the creator drops a voice memo transcript, text dump, memory, anecdote, character detail, theme idea, episode concept, or any raw creative material.

## Instructions

1. **Acknowledge** the idea briefly — show you understand what they shared
2. **Save the raw capture** to the appropriate folder:
   - Voice memos → `capture/voice-memos/YYYY-MM-DD-brief-topic.md`
   - Text dumps → `capture/text-dumps/YYYY-MM-DD-brief-topic.md`
3. **Tag the content** with categories: `[character]`, `[theme]`, `[episode-idea]`, `[memory]`, `[world-building]`, `[agency:gsp|wk|tbwa]`, `[tone]`, `[dialogue]`
4. **Route the information** to the right series bible section(s):
   - Character details → `docs/series-bible/02-characters.md`
   - Theme exploration → `docs/series-bible/03-themes.md`
   - Season/episode ideas → `docs/series-bible/04-season-arcs.md`
   - World details → `docs/series-bible/01-world.md`
   - Tone/style notes → `docs/series-bible/05-tone-and-style.md`
5. **Update the session log** in `planning/session-log.md` noting what was captured
6. **Flag any new open questions** that arise and add to `planning/open-questions.md`

## Model Usage
- Use **Haiku** for filing and formatting
- Use **Sonnet** for synthesizing ideas into existing documents
- Use **Opus** only if the idea requires big-picture story analysis

## Template for Raw Captures

```markdown
# [Date] - [Brief Topic]

## Raw Input
[Exact transcript or text dump]

## Tags
[character] [theme] [agency:x] [episode-idea] etc.

## Filed To
- docs/series-bible/XX-section.md (what was added)

## Notes
[Any observations, connections to other ideas, questions raised]
```
