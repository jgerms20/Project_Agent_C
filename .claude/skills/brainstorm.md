# Brainstorm

## When to Use
When the creator wants a structured creative conversation to explore open questions, develop ideas, or make decisions about the show. Use this instead of freeform chat when you want to make concrete progress on unresolved topics.

## Instructions

1. **Review open questions** — read `planning/open-questions.md` and identify the highest-impact unresolved topics
2. **Present 3-5 targeted questions** to the creator, drawn from open questions and tailored to what feels most productive right now. Prioritize:
   - High-priority blockers first
   - Questions that unlock multiple downstream decisions
   - Topics the creator has hinted at but not fully explored
3. **Probe deeper on each answer** — don't accept surface-level responses. Follow the thread:
   - "What does that look like in a scene?"
   - "How does that connect to [theme/character/era]?"
   - "What's the version of that idea that excites you most?"
   - "What's the opposite of that — and does it work better?"
   - "Is there a real memory behind that?"
4. **Capture all insights** as they emerge:
   - Save raw creative material to `capture/text-dumps/YYYY-MM-DD-brainstorm-[topic].md`
   - Tag with relevant categories: `[character]`, `[theme]`, `[episode-idea]`, `[world-building]`, `[structure]`, `[agency:gsp|wk|tbwa]`
5. **Update the series bible** with any decisions made during the conversation:
   - Character decisions → `docs/series-bible/02-characters.md`
   - Theme exploration → `docs/series-bible/03-themes.md`
   - Structure decisions → `docs/series-bible/04-season-arcs.md`
   - World details → `docs/series-bible/01-world.md`
   - Tone/style → `docs/series-bible/05-tone-and-style.md`
6. **Update open questions** — mark resolved questions as done, add new ones that surfaced
7. **End with a summary**:
   - What was decided (concrete decisions)
   - What was explored but not decided (needs more thought)
   - What new questions came up
   - Suggested next brainstorm topic

## Brainstorm Framing Tips
- Start with something specific, not abstract. "Tell me about a moment at W+K that stuck with you" beats "What's the W+K era about?"
- Use the show's own themes as lenses. E.g., "Where does cognitive dissonance show up in [this topic]?"
- If the creator is stuck, offer 2-3 options and let them react. Reaction is easier than generation.
- Don't rush to conclusions. Sit with ambiguity when the creator is still feeling it out.
- Circle back to the pilot often — it grounds abstract decisions in concrete storytelling.

## Model Usage
- Use **Opus** for running the brainstorm — big-picture thinking, thematic connections, asking the right questions
- Use **Sonnet** for capturing and writing up insights into docs
- Use **Haiku** for filing captures and updating logs
