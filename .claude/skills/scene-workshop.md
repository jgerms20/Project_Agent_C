# Scene Workshop

## When to Use
When the creator wants to develop a specific scene — from a raw memory or concept into drafted material with dialogue, tone, and pacing. Use this for hands-on writing work, not planning or outlining (use `episode-outline` for that).

## Instructions

1. **Establish context** — ask the creator:
   - Which agency era? (GSP / W+K / TBWA)
   - Which episode or season, if known? (Or standalone exploration)
   - Who's in the scene?
   - Where does it take place? (Office, bar, Zoom call, apartment, etc.)

2. **Get the scene seed** — what's the raw material?
   - A real memory or anecdote
   - A character conflict or dynamic
   - A thematic moment that needs dramatizing
   - A specific line of dialogue or image
   - A feeling or atmosphere

3. **Draft 2-3 approaches** to the scene, varying:
   - **POV**: Whose perspective drives it? (Protagonist? Antagonist? Bystander?)
   - **Tone**: Dramatic vs. darkly comic vs. surreal vs. understated
   - **Entry point**: Where do we enter the scene? (In medias res? Slow build? Cold?)
   - Present each approach as a 3-5 sentence pitch so the creator can react before full drafting

4. **Workshop the chosen approach**:
   - Draft dialogue — aim for natural, subtext-heavy conversation
   - Establish pacing — short punchy exchanges vs. long monologues vs. silence
   - Layer in subtext — what's not being said? What's the real conversation underneath?
   - Add stage direction / visual details that a showrunner would note
   - Check tone against `docs/series-bible/05-tone-and-style.md`

5. **Cross-reference with themes** — identify which core themes from `docs/series-bible/03-themes.md` this scene serves. Every scene should connect to at least one. Flag if it doesn't.

6. **Save the scene** to the appropriate location:
   - Pilot scenes → `scripts/pilot/scene-[brief-name].md`
   - Episode scenes → `scripts/episodes/SXX-EXX-scene-[brief-name].md`
   - Exploratory scenes (no episode yet) → `scripts/episodes/workshop-[date]-[brief-name].md`

7. **Update the session log**

## Scene Draft Template

```markdown
# Scene: [Brief Title]

## Context
- **Era**: GSP / W+K / TBWA
- **Episode**: S[X]E[XX] (or TBD)
- **Location**: [Where]
- **Characters**: [Who's present]
- **Time**: [When — time of day, year, context]

## Scene Seed
[The memory, idea, or conflict this scene is built from]

## Themes Served
[Which core themes this scene connects to]

## Draft

[The actual scene — description, dialogue, stage direction]

## Notes
- [Alternate approaches considered]
- [What's working, what needs more]
- [Connections to other scenes or episodes]
```

## Workshop Prompts (for pushing the scene further)
- "What if we cut the first half and started right at the tension?"
- "What's the version where nobody says what they mean?"
- "What does the room/space look like? What's the production design telling us?"
- "If this were the cold open, how would it change?"
- "What's the last image the audience sees before we cut?"

## Model Usage
- Use **Sonnet** for drafting scenes, dialogue, and descriptions
- Use **Opus** for evaluating tone, thematic alignment, and choosing between approaches
- Use **Haiku** for formatting and saving drafts
