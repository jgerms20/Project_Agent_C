# Session Review

## When to Use
At the end of every session, OR when the creator asks for a status check.

## Instructions

1. **Summarize what was accomplished** this session
2. **Update the session log** in `planning/session-log.md`
3. **Review and update open questions** in `planning/open-questions.md`
   - Remove any that were answered
   - Add any new ones that came up
4. **Update next steps** in `planning/next-steps.md`
5. **Check series bible sections** — are any stale or need updating based on today's work?
6. **Process any unprocessed captures** in `capture/` folders
7. **Commit all changes** with a clear message

## Session Summary Template

```markdown
## Session [N] - [Date] - [Brief Title]

### What We Accomplished
- [Bullet points of concrete outputs]

### Decisions Made
- [Any new decisions with rationale]

### Ideas Captured
- [New ideas, memories, or concepts that came up]

### Open Questions Added
- [New questions to resolve]

### Open Questions Resolved
- [Questions that got answered]

### Next Session Priorities
1. [Most important thing to tackle next]
2. [Second priority]
3. [Third priority]
```

## Model Usage
- Use **Haiku** for updating logs and formatting
- Use **Sonnet** for synthesizing session insights
