# Character Profile

## When to Use
When the creator wants to add a new character, flesh out an existing one, or explore character dynamics and relationships.

## Instructions

1. **Interview the creator** about the character if details are sparse. Ask about:
   - Who is this character based on (if anyone)?
   - What role do they play in the protagonist's journey? (mentor, rival, mirror, love interest, comic relief, antagonist, ally)
   - Which agency era(s) do they appear in?
   - What's their deal — what drives them, what's their contradiction?
   - One defining scene or moment you envision for them

2. **Build the profile** using the template below

3. **Update** `docs/series-bible/02-characters.md` with the new or updated profile

4. **Cross-reference** — check if this character connects to existing themes, plot points, or other characters

5. **Update the session log**

## Character Profile Template

```markdown
### [Character Name] (fictionalized) / [Real Inspiration] (if applicable)

**Agency Era(s)**: GSP / W+K / TBWA / Multiple
**Role in Story**: [mentor / rival / mirror / love interest / comic relief / antagonist / ally / wildcard]
**Archetype**: [one-line archetype description]

**Who They Are**: [2-3 sentences — position, personality, what makes them distinct]

**What Drives Them**: [Core motivation]

**Their Contradiction**: [The gap between who they present as and who they are]

**Key Relationships**: [How they relate to protagonist and other characters]

**Signature Moments**: [Scenes or beats you envision for them]

**Arc**: [How they change across the series, if they do]

**Inspired By**: [Real person/composite/original — and what specifically is drawn from reality]
```

## Model Usage
- Use **Sonnet** for character development and profile writing
- Use **Opus** for analyzing character dynamics and ensemble chemistry
