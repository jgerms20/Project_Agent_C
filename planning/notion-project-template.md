# Notion Project Template: THE AGENCY / AGENCY

## How to Set Up
Copy this structure into a new Notion workspace page. This is designed for **mobile-first day-to-day use** — quick captures, clear to-dos, and at-a-glance status.

---

## Page Structure

### 1. Dashboard (Home Page)
Create a page called **"The Agency / Agency"** with these linked databases and sections:

### 2. To-Do Database
Create a **database** called "Tasks" with these properties:
- **Task** (title)
- **Status** (select): Not Started, In Progress, Done, Blocked
- **Priority** (select): Must Do, Should Do, Nice to Have
- **Category** (select): Character, Writing, Research, Site, Planning, Interview
- **Due Date** (date)
- **Notes** (text)

### 3. Characters Database
Create a **database** called "Characters" with these properties:
- **Name** (title) — fictionalized name
- **Real Inspiration** (text)
- **Agency Era** (multi-select): GSP, W+K, TBWA, Multiple
- **Role** (select): Mentor, Rival, Mirror, Love Interest, Comic Relief, Antagonist, Ally, Wildcard
- **Status** (select): Named Only, Sketch, Draft Profile, Complete
- **Key Trait** (text) — one-line hook
- **Arc** (text)

Pre-populate with the 25+ names from Session 1.

---

### 4. Episodes Database
Create a **database** called "Episodes" with these properties:
- **Title** (title)
- **Season** (select): S1, S2, S3, S4, S5
- **Episode #** (number)
- **Era** (select): GSP, W+K, TBWA
- **Tone** (select): Dramatic, Dark Comedy, Surreal, Mixed
- **Central Theme** (select from the 10 themes)
- **Status** (select): Concept, Outlined, Drafted, Revised, Final
- **Logline** (text)
- **Key Scenes** (text)

---

### 5. Captures / Ideas Inbox
Create a simple **database** called "Ideas" with:
- **Idea** (title)
- **Type** (select): Memory, Scene, Dialogue, Character Beat, Theme, Music, Visual
- **Era** (select): GSP, W+K, TBWA, General
- **Filed?** (checkbox) — has this been processed into the series bible?
- **Notes** (text)

This is your mobile capture tool. Drop voice memo notes, shower thoughts, and text dumps here.

---

### 6. Research Hub
Create a **database** called "Research" with:
- **Topic** (title)
- **Agency** (select): GSP, W+K, TBWA, Industry General
- **Type** (select): Agency History, Cultural Context, Industry Event, Legal, Music
- **Status** (select): To Research, In Progress, Complete
- **Key Findings** (text)
- **Show Relevance** (text) — how this feeds the series

---

### 7. Session Notes
Create a simple page or database for session notes after each Claude Code working session. Link back to the GitHub site for the full series bible.

---

## Views to Create

### Kanban Board (Tasks)
Group by Status. This is your daily driver on mobile.

### Calendar View (Tasks)
For deadline tracking if you set target dates.

### Characters by Era (Characters)
Filter by Agency Era. Quick reference for which characters appear when.

### Ideas Inbox (Ideas)
Filter: Filed? = false. Shows only unprocessed captures.

---

## Mobile Tips
- Pin the Dashboard and Tasks pages to your Notion sidebar
- Use the Quick Capture block at the top of Dashboard for fast ideas
- The Ideas database with "Filed?" checkbox lets you quickly triage on the go
- Use Notion's mobile widget for instant capture without opening the app
