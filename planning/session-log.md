### Key Decisions Made

| Decision | Choice | Notes |
|----------|--------|-------|
| Format | Half-hour hybrid | Standalone eps building larger arcs (Atlanta model) |
| First deliverable | Series Bible | Before scripts |
| Tone | Drama-forward + dark humor | Episode-dependent shifts. Some funny, some devastating. |
| Protagonist | Fictionalized creator + ensemble | Lead is fictionalized self, but multiple POVs |
| Protagonist arc | Outsider → disruptor | Enters naive, eventually masters and subverts the system |
| Timeline structure | Season = era + non-linear | Each season covers an agency, with jumps and blended timelines |
| Season count | 4-5+ | Some eras get expanded or post-agency arc exists |
| AI in narrative | Slow burn → crescendo | Easter eggs early, protagonist uses as catalyst |
| Race in narrative | Central + interwoven + subtext | Flexes up and down by episode |
| MAIP role | Connective tissue + more TBD | Creator wants to explain further |
| Capture workflow | Voice memos + Claude mic + text dumps | Mix of methods, phone-first |
